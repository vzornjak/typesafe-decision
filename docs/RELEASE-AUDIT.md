# Public Release Audit — v2.5.0

**Audit date:** 2026-09-20
**Scope:** the public repository tree only
**Release posture:** experimental, advisory, unofficial TypeSafe/Jev integration for Minis

## Release decision

**PASS for public source release**, with one explicit product limitation: **P0-6 remains PARTIAL**. The invalid shortlist-quality claim is retracted and regression-locked, but no clean replacement benchmark exists. `shortlist` therefore remains experimental and must not be presented as validated or enabled as an authorization mechanism.

## Portability and sanitization changes

1. Absolute dependencies on local workspace fixtures were removed.
2. Private replay data was replaced by deterministic synthetic fixtures generated by `tests/generate_fixtures.py`.
3. `TYPESAFE_DEFAULT_LOG` was added as an optional override while preserving the Minis default when unset.
4. Tests repoint the default log to an isolated temporary file before importing runtime modules.
5. Upstream-license verification uses a pinned byte hash instead of requiring a local checkout.
6. Stray-artifact checks scan the repository rather than a local working directory.
7. Fixture child environments use the platform temporary directory instead of a fixed host path.
8. The P0-6 retraction was promoted from an internal note to public documentation.

No regression test was removed or duplicated to produce the published count.

## Known limitations

- Jev signals and the injection score are advisory, not security boundaries.
- Key-name scrubbing does not inspect free-text values; caller-side minimization is mandatory.
- Retry behavior is tested with deterministic stub transports, not paid live 429/5xx traffic.
- The character-based request budget is a conservative proxy, not exact tokenization.
- Legacy production rows predating schema 4 are outside this repository.
- No valid shortlist quality benchmark currently exists; see `RETRACTION-shortlist-v1.1.md`.

## Audit interpretation

Passing this release audit means the public source tree is portable, reproducibly tested, and free of detected secrets/private artifacts under the implemented scanners. It does **not** certify model quality, authorize risky actions, or make this an official TypeSafe AI product.
